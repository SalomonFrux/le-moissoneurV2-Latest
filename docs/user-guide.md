# Le Moissoneur V2 User Guide

## Introduction
Le Moissoneur V2 is a powerful web scraping tool designed to help you collect and analyze data from websites efficiently and reliably.

## Getting Started

### Setting Up a New Scraper

1. **Navigate to the Scraper Setup Page**
   - Click "New Scraper" in the dashboard
   - Enter the target website URL
   - Choose a name for your scraper

2. **Using the Visual Setup Wizard**
   - Click elements on the page you want to capture
   - The system will automatically suggest selectors
   - Confirm the selected elements

3. **Field Configuration**
   - Name your fields (e.g., "title", "price", "description")
   - The system will automatically detect field types
   - You can manually adjust if needed

### Running Your Scraper

1. **Starting a Scraping Job**
   - Click "Start Scraping" on your configured scraper
   - Monitor progress in real-time
   - View collected data as it comes in

2. **Monitoring Progress**
   - Watch the status dashboard
   - Check data quality metrics
   - Monitor performance statistics

### Understanding Alerts

#### Alert Types
1. **Info Alerts (Blue)**
   - Progress updates
   - Status changes
   - General information

2. **Warning Alerts (Yellow)**
   - Slower than expected performance
   - Minor data quality issues
   - Configuration suggestions

3. **Error Alerts (Red)**
   - Failed scraping attempts
   - Connection problems
   - Critical issues

#### Responding to Alerts

1. **Data Quality Alerts**
   - Review the affected fields
   - Check selector configuration
   - Update field definitions if needed

2. **Performance Alerts**
   - Consider reducing concurrent requests
   - Check network connectivity
   - Adjust timing settings

3. **Security Alerts**
   - Review access patterns
   - Check IP restrictions
   - Contact support if needed

### Managing Data

1. **Viewing Results**
   - Navigate to the "Results" tab
   - Filter and sort data
   - Preview content

2. **Exporting Data**
   - Select export format (CSV, JSON, Excel)
   - Choose fields to include
   - Download the file

3. **Data Quality Tools**
   - Check field accuracy
   - Validate data formats
   - Review missing data reports

### Best Practices

1. **Configuration Tips**
   - Start with small test runs

2. **Performance Optimization**

3. **Maintenance**
